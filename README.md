# PNK Workshop — ใบเขียน PRD สำหรับผลิตภัณฑ์ AI

ใบกรอก PRD แบบหน้าเดียว ใช้ในเวิร์กช็อป AI Transformation โรงพยาบาลพระนั่งเกล้า

เปิดใช้งาน: https://punthirachin.github.io/pnk-workshop/

- คลิกช่องไหนก็ได้เพื่อพิมพ์ทับ — บันทึกอัตโนมัติในเบราว์เซอร์เครื่องนั้น
- กด **⬇ ส่งออก JSON** เพื่อเก็บไฟล์ไปใช้ต่อ
- กด **พิมพ์ / PDF** เพื่อพิมพ์เป็นกระดาษ

ตัวเลขในตัวอย่างที่กรอกไว้เป็น **ตัวเลขสมมติเพื่อการสอน** ไม่ใช่ข้อมูลจริงของโรงพยาบาล
