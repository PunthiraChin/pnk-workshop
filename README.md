# ใบเขียน PRD สำหรับผลิตภัณฑ์ AI

ใบกรอกแบบหน้าเดียว สำหรับออกแบบผลิตภัณฑ์ที่มี AI ให้ครบ ๘ บล็อก — ปัญหาและผู้ใช้ · เป้าหมายและตัวชี้วัด · ขอบเขต · สถานการณ์ · ข้อมูลและความรู้ · guardrail · test case และเกณฑ์ยอมรับ · เครื่องมือและเจ้าของ

เปิดใช้งาน: https://punthirachin.github.io/pnk-workshop/

- คลิกช่องไหนก็ได้เพื่อพิมพ์ทับ — บันทึกอัตโนมัติในเบราว์เซอร์เครื่องนั้น
- กด **⬇ ส่งออก JSON** เพื่อเก็บไฟล์ไปใช้ต่อ
- กด **พิมพ์ / PDF** เพื่อพิมพ์เป็นกระดาษ

> ตัวอย่างที่กรอกไว้เป็น **แชตบอทถาม-ตอบของโรงพยาบาลรัฐสมมุติ** ตัวเลขทั้งหมดแต่งขึ้นเพื่อการสอน ไม่ใช่ข้อมูลของโรงพยาบาลแห่งใด
